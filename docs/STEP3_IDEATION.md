# 3단계: 아이디어 내기 · 3조 작성 초안

본 문서는 기존 「3조 문제정의 워크시트」(1단계 공감하기·2단계 문제정의)를 기초로 작성한 **초안**이며, 조원 의견을 받은 후 아이디어를 추가·수정합니다.

## 1. 아이디어 발상 질문 (How Might We)

**어떻게 하면 입·퇴원이 잦은 병동의 간호사가 반복적으로 설명하는 데 소요되는 시간을 줄이면서, 환자의 개별 특성에 맞는 중요한 교육 내용을 빠뜨리지 않고 제공하고, 환자가 실제로 이해했는지도 확인할 수 있을까?**

세부 질문:
- 어떻게 하면 간호사가 환자의 입원/퇴원 및 진료과에 따라 필요한 교육을 손쉽게 구성할 수 있을까?
- 어떻게 하면 고령자와 시력·청력 등 의사소통 요구가 다른 환자들이 자기 속도에 맞춰 설명을 이해할 수 있을까?
- 어떻게 하면 화면상 교육 이수 여부와 실제 이해 정도를 구분하여 간호사가 확인할 수 있을까?

## 2. 브레인라이팅 아이디어 목록 (조원 의견 전 초기안)

1. **공통·부서별·개별 교육 모듈 선택:** 입원/퇴원과 진료과에 따라 필요한 내용을 조합하는 체크리스트.
2. **큰 글씨·고대비·음성 속도 조절:** 환자가 선택하는 접근성 조절.
3. **한 화면 한 주제 카드형 안내:** 길고 복잡한 안내를 단계별로 짧게 전달.
4. **음성 읽기·일시정지·반복 듣기:** 간호사의 반복적인 구두 설명을 보조.
5. **환자 이해도 자기 점검 및 질문 전달:** 이해한 항목과 다시 설명받을 항목을 표시.
6. **간호사 Teach-back 최종 확인:** 환자가 자신의 말로 설명하고 간호사가 직접 확인 후 보충교육.
7. **교육 상태 대시보드:** 대기·진행 중·구두 확인 대기·추가 설명 필요·확인 완료를 구분.
8. **병원 교육자료 승인·이력 관리:** 승인된 콘텐츠만 사용하고 개정일·담당자를 관리하는 향후 기능.
9. **출력·보호자 동반 안내:** 디지털 기기를 사용하기 어려운 환자의 대체 경로.
10. **기관 시범 운영 평가:** 교육 시간, 정보 누락, 환자 이해도, 간호사 만족도 지표를 비교.

위 아이디어는 연구나 운영 결과가 아니라 브레인스토밍에서 나온 **개발 후보**입니다.

## 3. AI 대화 및 MVP 구성 요소 (과제 필수 6요소)

| 항목 | 제안 |
|---|---|
| 사용자 | 입·퇴원이 잦은 통원수술센터·외과병동·혈액종양내과 간호사(주 사용자), 교육받는 환자(최종 사용자) |
| 문제 | 구두교육 반복으로 인한 업무 과중, 환자별 건강정보 이해도 차이, 교육 누락 우려와 실제 이해 확인의 어려움 |
| 사용환경 | 입원 안내·수술 준비·퇴원 교육이 집중되는 병원 근무 시간; 간호사의 PC/태블릿 및 병원에서 환자에게 제공된 기기 |
| 해결 아이디어 | 병원 승인 교육자료를 모듈로 구성하여 환자가 글씨·음성 조건을 조절하며 교육받고, 간호사가 구두로 이해도를 최종 확인 |
| 핵심기능 | 환자/교육 시점 선택, 교육 모듈 구성, 맞춤형 표시/음성, 반복 듣기, 자기 점검, 구두 확인·재교육 체크리스트 |
| 결과물 | ① 의료진 환자·교육 선택 화면 ② 환자용 카드형 교육 화면 ③ 이해도 자기 점검 화면 ④ 간호사의 최종 확인 화면 ⑤ 근거·기대효과 구분 화면 |

## 4. MVP 범위 및 구현 순서

**MVP v0.1 구현:** 가상 환자 3명, 모듈 선택, 교육 카드, 기본 접근성 기능, 환자 자기 점검, 간호사 최종 확인, 상태 표시, 연구 근거와 미검증 기대효과 구분.

**후속 검토:** 조원 의견 통합, 실제 병원 지침 검토를 거친 콘텐츠 승인 절차, 안전한 인증과 관리 권한, 접근성·사용성 시험, 기록 및 EMR 연계 타당성 검토.

## 5. 기대효과와 검증된 결과 구별

- **문헌 근거가 있는 원칙:** 이해하기 쉬운 환자교육, 건강정보 이해능력을 고려한 구성, Teach-back을 통한 이해 확인 (AHRQ; CDC).
- **이 프로그램에서 아직 검증되지 않은 기대효과:** 교육시간 단축, 간호사의 피로·업무 부담 감소, 교육 누락 감소, 환자의 이해도 향상.
- **이번 시연에서 확인 가능한 구현 여부:** 가상 데이터로 사용자 화면과 단계별 흐름을 조작하는 것.
- **필요한 추가 검증:** 실제 사용자 인터뷰, 임상 전문인의 자료 검토, 기능/보안/접근성 시험, 교육 전후 비교 지표 측정.
